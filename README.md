# DevInspector Ultra

Компактное приложение для детальной аппаратной диагностики и анализа низкоуровневых параметров устройств на базе Android.

---

## Описание

DevInspector Ultra — легковесная утилита (~95 КБ) для получения подробной информации об аппаратной части устройства, операционной системе и ядре Linux. Приложение выполнено без сторонних библиотек и тяжелых фреймворков на чистом Android API и прямом чтении интерфейсов ядра.

Интерфейс спроектирован в строгой монохромной палитре (чёрный, белый и градации серого) без цветных акцентов и эмодзи.

APK-пакет выровнен по 4-байтовой границе (ZipAlign) и подписан двойной схемой v1 (JAR) и v2 (APK Signature Scheme v2), что обеспечивает установку на версии Android от 5.0 до 15+.

## Разделы диагностики

### 1. Общий обзор (Overview)
- Производитель, модель, плата (Board), системный продукт.
- Платформа/SoC, архитектура и количество вычислительных ядер.
- Версия Android, уровень API, дата патча безопасности Google.
- Статистика оперативной памяти (RAM) и внутреннего накопителя.
- Уровень заряда и статус аккумулятора.
- Разрешение экрана, плотность DPI и частота обновления (Гц).
- Время непрерывной работы системы (Uptime).
- Проверка наличия прав суперпользователя (Root) и статус SELinux.

### 2. Центральный процессор (CPU)
- Идентификатор SoC и чипсета.
- Архитектура и разрядность (32-bit / 64-bit).
- Список поддерживаемых ABI (arm64-v8a, armeabi-v7a).
- Мониторинг частоты каждого ядра в реальном времени.
- Минимальные, текущие и максимальные частоты масштабирования.
- Регулятор частоты (CPU Governor).
- Набор инструкций процессора из `/proc/cpuinfo` (FP, ASIMD/NEON, AES, SHA, CRC32).
- Технические поля: CPU Implementer, Architecture, Variant, Part, Revision, BogoMIPS.

### 3. Оперативная память и накопители
- Объём RAM: общий, занятый, свободный, порог срабатывания Low-Memory Killer.
- Расширенная статистика ядра из `/proc/meminfo` (Buffers, Cached, Active, Inactive, Dirty, Writeback).
- Состояние ZRAM и Swap-компрессии.
- Статистика раздела пользователя (`/data`) и системного раздела (`/system`).
- Таблица активных точек монтирования файловых систем (`/proc/mounts`).

### 4. Аккумулятор и система питания
- Процент заряда и статус (зарядка / разрядка / полный заряд).
- Источник питания (сеть AC, USB, беспроводная зарядка).
- Состояние здоровья аккумулятора (Health).
- Технология батареи (Li-ion, Li-poly).
- Температура электролита (в °C или °F).
- Текущее напряжение (мВ).
- Паспортная ёмкость (мАч) через системный класс `com.android.internal.os.PowerProfile`.
- Мгновенный ток зарядки/разрядки (мА).

### 5. Экран и графический ускоритель
- Физическое разрешение матрицы и доступная рабочая область.
- Расчётная диагональ экрана в дюймах.
- Плотность пикселей (DPI, X-DPI, Y-DPI) и категория плотности.
- Частота обновления экрана (60, 90, 120, 144 Гц) и список поддерживаемых режимов.
- Поддержка HDR-профилей (Dolby Vision, HDR10, HDR10+, HLG).
- Поддержка расширенного цветового охвата (Wide Color Gamut).
- Версия OpenGL ES.

### 6. Сетевые подключения и связь
- Wi-Fi: SSID, BSSID, уровень сигнала (RSSI в dBm), рабочая частота (2.4 / 5 / 6 ГГц), скорость линка, MAC-адрес.
- IP-адресация: IPv4 и глобальные/локальные IPv6 адреса активных интерфейсов.
- Мобильная сеть: оператор связи, коды страны и сети (MCC/MNC), тип сети (5G NR, LTE, HSPA, EDGE).
- Беспроводные интерфейсы: Bluetooth (включая BLE, 2M PHY, LE Coded), NFC, Wi-Fi Direct, UWB, ИК-порт.

### 7. Аппаратные датчики
- Полный перечень зарегистрированных сенсоров устройства (акселерометр, гироскоп, магнитометр, датчик освещения, датчик приближения, барометр).
- Производитель, вендор, версия, энергопотребление (мА) и диапазон измерений каждого датчика.
- Интерактивный монитор: выбор любого датчика для отображения текущих координат и значений в реальном времени.

### 8. Модули камер
- Опрос Camera2 API: тыловые и фронтальные сенсоры.
- Разрешение матриц в мегапикселях и точные размеры кадра.
- Физические размеры матриц и расчётный размер пикселя в микрометрах.
- Фокусные расстояния и апертура (диафрагменное число f-number).
- Поддержка оптической (OIS) и электронной (EIS) стабилизации.
- Аппаратный уровень интеграции (LEGACY, LIMITED, FULL, LEVEL_3).

### 9. Температурные зоны
- Опрос температурных зон ядра из `/sys/class/thermal/thermal_zone*`.
- Температуры вычислительных ядер, графического чипа, модема, батареи и корпуса.
- Статус троттлинга через системный `PowerManager.getThermalHeadroom()`.

### 10. Мультимедиа, кодеки и DRM
- Аппаратные и программные декодеры и энкодеры системы (AVC, HEVC, AV1, VP9, Opus, AAC, FLAC).
- Опрос Widevine CDM через `MediaDrm`:
  - Уровень безопасности (Security Level L1 / L3).
  - Идентификатор системы (System ID).
  - Версия библиотек Widevine.

### 11. Низкоуровневые и системные параметры
- Чтение параметров командной строки ядра из `/proc/cmdline`.
- Системные флаги безопасности и загрузчика:
  - `ro.boot.verifiedbootstate` (статус Android Verified Boot: green, yellow, orange, red).
  - `ro.boot.flash.locked` (блокировка загрузчика).
  - `ro.boot.vbmeta.device_state` (состояние структуры VBMeta).
  - `ro.boot.slot_suffix` (активный слот A/B обновлений).
  - `ro.bootmode` (режим загрузки: normal, recovery, fastboot).
  - `ro.boot.hardware.sku` и `ro.boot.hardware.revision`.
  - `ro.boot.warranty_bit` (счётчик Knox).
  - `ro.secure`, `ro.debuggable`, `ro.adb.secure`.
  - `ro.crypto.state` и `ro.crypto.type` (алгоритм шифрования FBE).
  - `ro.treble.enabled`, `ro.build.ab_update`, `ro.apex.updatable`.
- Инспекция системных IPC-сервисов через Binder `ServiceManager.listServices()`.
- Реестр криптографических модулей ядра из `/proc/crypto`.
- Список инженерных кодов для номеронабирателя.

### 12. Свойства системы (getprop)
- Полный дамп системных свойств устройства.
- Поиск по ключам и значениям в реальном времени.
- Фильтрация по категориям (Android, Загрузка, Вендор, Безопасность, Сеть).
- Копирование любого свойства в буфер обмена по нажатию.

### 13. Параметры и экспорт
- Выбор темы оформления: «Чёрный» (OLED pitch black), «Графит» (тёмно-серый) или «Сталь» (холодный нейтральный серый).
- Выбор единиц измерения: температура (°C / °F), частота процессора (МГц / ГГц).
- Настройка периода обновления данных (1 сек, 2 сек, 5 сек или отключено).
- Переключатель глубокого анализа IPC-сервисов.
- Экспорт полного текстового отчёта со всеми параметрами в буфер обмена или через стандартное системное меню «Поделиться».

## Сборка

Сборка осуществляется через автономный скрипт без использования сторонних сборочных систем:

```bash
./build.sh
```

Этапы конвейера:
1. `aapt2 compile` и `aapt2 link` — сборка ресурсов и манифеста.
2. `ecj` — компиляция исходного кода Java 8.
3. `d8` — трансляция байт-кода в Dalvik Executable (`classes.dex`).
4. `zip` — упаковка dex-файла в базовый пакет без сжатия ресурсов.
5. `zipalign` — выравнивание всех записей архива по 4-байтовой границе.
6. `apksigner` — формирование цифровой подписи по схемам v1 и v2.
7. Проверка целостности через `apksigner verify --verbose` и валидация через `Androguard`.
