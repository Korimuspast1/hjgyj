# 🎰 CaseArena — симулятор открытия кейсов CS2

Сайт-игра: зарабатывай деньги кликами, открывай кейсы и выбивай **любой скин из CS2**, собирай инвентарь и продавай дропы.

## Возможности

- **💰 Кликер** — зарабатывай деньги кликами по монете, прокачивай силу клика, шанс крита (×10) и пассивную «дроп-ферму»
- **📦 15 кейсов** — от «Кейса новичка» за $5.80 до «Золотого» за $8 125: тематические (пистолетный, винтовочный, снайперский, «Ножи», «Перчатки», StatTrak™, сувенирный) 
- **🔫 Все скины CS2** — 1 974 уникальных скина с официальными картинками Steam CDN: названия, редкости, диапазоны float, StatTrak™, сувенирные версии, ванильные ножи и даже M4A4 | Howl (Контрабанда)
- **🎡 Рулетка открытия** — анимация в стиле CS с карточками скинов, маркером и возможностью пропустить
- **🎒 Инвентарь** — поиск, сортировка (цена/редкость/дата), продажа по одному, «продать хлам» (≤$50) и «продать всё»
- **🎚 Экономика** — цены скинов зависят от редкости, износа (FN→BS), float, StatTrak™/сувенира; шансы редкостей — как в настоящих кейсах CS2
- **🎨 Кастомные SVG-иконки** — весь спрайт нарисован вручную (кейсы, монета, нож, перчатка, оружие, корона и т.д.)
- **🔊 Звуки** — синтезируются на лету через WebAudio (клики, криты, продажа, выигрыши)
- **💾 Прогресс** — автоматически сохраняется в localStorage

## Запуск

Статический сайт — достаточно любого HTTP-сервера:

```bash
# Python
python3 -m http.server 3000 --bind 0.0.0.0

# или Node
npx serve .
```

Открой `http://localhost:3000`.

## Структура

```
index.html          — разметка + кастомный SVG-спрайт иконок
css/style.css       — стили (тёмная игровая тема)
js/app.js           — вся логика (кликер, кейсы, рулетка, инвентарь, цены, звук)
data/skins.json     — компактный датасет всех скинов CS2 (~700 КБ)
tools/build-data.mjs— скрипт сборки датасета из ByMykel/CSGO-API
tools/smoke/smoke.mjs — смоук-тест (jsdom): 44 проверки основных сценариев
```

## Данные скинов

Датасет собран из открытой базы [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) —
полный список скинов CS2 с названиями, редкостями, float и ссылками на картинки
(официальный CDN Steam). Обновить данные:

```bash
curl -sL https://bymykel.github.io/CSGO-API/api/en/skins.json -o /tmp/skins_raw.json
node tools/build-data.mjs /tmp/skins_raw.json data/skins.json
```

## Тесты

cd tools/smoke && npm install && cd ../..
node tools/smoke/smoke.mjs
