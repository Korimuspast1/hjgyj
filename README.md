# NOVA X5 Pro — симулятор телефона

Браузерная игра-симулятор: вы только что купили смартфон **NOVA X5 Pro**. Всё как в жизни —
коробка, защитная плёнка, скрепка для SIM-лотка, выбор оператора, мастер первоначальной
настройки… а потом полноценная операционная система **NovaOS 15** с 18 приложениями,
мессенджером с живыми собеседниками, шторкой уведомлений, интернетом, звонками, банком и
магазином приложений.

Никаких зависимостей и сборки: чистый HTML + CSS + ES-модули. Открыл `index.html` — играешь.

---

## Запуск

Вариант 1 — просто открыть файл:

```
index.html   (двойной клик)
```

Вариант 2 — локальный сервер (нужен, если браузер капризничает с модулями по `file://`):

```bash
cd hjgyj
python3 -m http.server 8080 --bind 0.0.0.0
# → http://localhost:8080
```

Прогресс автоматически сохраняется в `localStorage` под ключом `nova-x5-pro-save-v1`.
Кнопка **«Новая игра»** на стартовом экране начинает всё сначала.

## С чего начинается игра

Игра стартует не с домашнего экрана, а со **стола, на котором лежит коробка**:

| Шаг | Что делать |
|-----|------------|
| 1 | Кликнуть по коробке — вскрыть |
| 2 | Вытащить телефон вверх из коробки (перетащить) |
| 3 | Потянуть ярлычок защитной плёнки и снять её |
| 4 | Взять со стола скрепку |
| 5 | Нажать скрепкой маленькое отверстие на правой грани — лоток выезжает |
| 6 | Перетащить SIM-карту в лоток |
| 7 | Задвинуть лоток обратно в телефон |
| 8 | Выбрать оператора: **Mobiline** (12 €/день, безлимитный интернет) или **Telka** (8 €/день, 15 ГБ) |
| 9 | Зажать кнопку питания справа (~1 с) — телефон включится |
| 10 | Пройти мастер настройки: язык → Wi-Fi → мобильные данные → отпечаток пальца → PIN-код → имя владельца |

На каждом шаге есть подсказка-коучмарк. Wi-Fi домашней сети: **Home_Nova_5G**, пароль
`kotenok2024` — он написан на роутере, который тоже лежит на столе.

После настройки начинается «жизнь»: мама пишет первая, потом подтягиваются Кирилл, папа,
Аня, оператор и спамеры. Кто-то звонит, кто-то присылает голосовые.

## Что есть на телефоне

**Система**

- Домашний экран: 2 страницы, виджеты погоды и плеера, док, поиск по приложениям, ящик приложений
- Долгое нажатие на иконку → контекстное меню (Открыть / О приложении / Удалить)
- Недавние приложения с живыми снимками содержимого, выгрузка одного или всех
- Шторка уведомлений: 12 плиток быстрых настроек, слайдеры яркости и громкости, автояркость,
  уведомления (открыть, закрыть, «Очистить всё»), «Не беспокоить», режим полёта, фонарик, точка доступа
- Экран блокировки: часы, дата, уведомления, быстрые кнопки камеры и фонарика, свайп вверх → PIN-пад,
  разблокировка отпечатком (удержание)
- Физические кнопки: питание (короткое нажатие — экран, удержание — меню питания с перезагрузкой,
  выключением и экстренным вызовом 112), громкость (с HUD)
- Батарея: разряд, нагрев, зарядка от кабеля на столе, режим экономии, смерть при 0% и «мёртвый экран»
- Время идёт с ускорением (по умолчанию 1 игровая минута ≈ 1 реальная секунда), смена суток,
  ежедневная абонплата оператора в 9:00, утренняя/вечерняя переписка

## Прогресс

- **15 задач** — короткие цели («снять плёнку», «подключить Wi-Fi», «ответить маме», «позвонить», «поставить на зарядку»…)
- **40 достижений** — от «Распаковка» и «Свежий экран» до «Разрядился», «Транжира», «Полуночник» и «Бдительность»
- **Статистика** — отправленные и полученные сообщения, звонки и минуты, снимки, мегабайты трафика,
  покупки, переводы, рекорд в змейке, число разблокировок

---

## Режим разработчика

Настройки → О телефоне → **7 раз нажать «Номер сборки»**. Появятся отладочные пункты:
скорость времени, управление батареей и деньги (+50 € на карту или наличными).

## Как устроен код

```
index.html          сцена стола, корпус телефона, слои экрана, шторка, системные оверлеи
css/                base.css · phone.css · system.css · apps.css
js/
  main.js           точка входа: инициализация, восстановление сейва, глобальные хуки
  state.js          всё состояние игры + сохранение/загрузка
  bus.js            события (EV.TIME, EV.NET, EV.MESSAGE, EV.BATTERY…)
  api.js            интерфейс, через который приложения говорят с системой
  registry.js       реестр приложений, раскладка домашнего экрана, каталог магазина
  phone.js          питание, экран, блокировка, стек приложений, недавние, меню питания
  desk.js           стол: коробка, плёнка, скрепка, SIM, лоток, тарифы, зарядка
  setup.js          мастер первоначальной настройки
  shade.js          шторка, плитки быстрых настроек, уведомления
  lock.js           экран блокировки, PIN-пад, отпечаток, недавние
  net.js            Wi-Fi, мобильные данные, лимиты трафика, «интернет есть/нет»
  notify.js         уведомления, heads-up, тосты
  achievements.js   40 достижений
  time.js           игровое время, батарея, сигнал, события суток, абонплата
  audio.js          весь звук синтезируется через WebAudio (без файлов)
  icons.js          ~96 SVG-иконок
  ui.js             диалоги, тосты, коучмарки, модалки мира
  home.js           домашний экран, ящик, папки, контекстное меню
  apps/             18 приложений и generic.js для установленных из магазина
```

Приложение — это модуль с `mount(root, api, params)`, который возвращает
`{ onFocus, onBack, onUnmount }`. Всё взаимодействие идёт через `api` (`openApp`, `back`,
`goHome`, `notify`, `toast`, `unlock`…), поэтому приложения ничего не знают друг о друге.

## Тесты

В `tests/` — jsdom-обвязка, которая запускает игру без браузера и кликает по ней как человек.

```bash
cd tests
npm install                 # jsdom, acorn, acorn-walk

node undeclared.mjs         # ~1 с: статический поиск необъявленных/неимпортированных имён
node suite.mjs              # ~6 мин: полный прогон игры, 350+ проверок
node suite.mjs --quick      # ~2 мин: то же, но с укороченными паузами
```

`suite.mjs` проходит всю игру с нуля — распаковка, мастер настройки, домашний экран, шторка,
мессенджер, звонки и USSD, браузер и покупки, камера с галереей, банк, магазин приложений,
все остальные приложения, 12 разделов настроек, OTA-обновление, блокировка и PIN, батарея,
перезагрузка и выключение, сохранение, смена суток с абонплатой — и печатает ✅/❌ по каждому
пункту, а в конце сводку и все JS-ошибки. Код возврата: `0` — всё зелёное, `1` — есть замечания.

`undeclared.mjs` ловит отдельный класс ошибок, который не виден ни парсеру, ни ручному прогону:
использование имени без импорта (например `$`, `rndInt`, `OPERATORS`) — такие падения происходят
только на конкретном пути кода, уже у игрока.

## Мелочи, которые приятно заметить

- Плёнка снимается с характерным «отлипающим» движением, а звук синтезируется в моменте
- Статус-бар показывает реальный уровень сигнала, тип сети (5G/LTE/Wi-Fi), процент и charging
- В разговоре приложение сворачивается в компактную плашку — можно листать ленту во время звонка
- Экран блокировки показывает уведомления, а свайп вверх ведёт к PIN-паду с буквами на клавишах
- Браузер честно считает трафик: по Wi-Fi безлимит, по мобильной сети мегабайты уходят в пакет
- Мошеннические сайты можно заблокировать, и они попадут в список блокировок
- OTA-обновление реально меняет номер сборки и версию ОС в «О телефоне»
- Если разрядить телефон в ноль — он выключится, и поможет только кабель со стола
