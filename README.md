# DEADBLOCK — 2D пиксельная зомби-симуляция

**DEADBLOCK** — top-down выживалка в стиле *Project Zomboid*: процедурно генерируемый
город, зомби с ИИ, физика, лут, крафт, цикл дня и ночи. Всё рисуется кодом —
ни одного внешнего ассета: пиксель-арт тайлов, персонажей, иконок и звуков
генерируется процедурно.

```
Формат:  HTML5 Canvas 2D + ES-модули (без сборки, без зависимостей)
Размер:  200 x 150 тайлов (3200 x 2400 px) — один город на сид
```

---

## Запуск

```bash
python3 -m http.server 8000      # из корня репозитория
# открыть http://localhost:8000
```

или `npm start`. Нужен любой статический HTTP-сервер (ES-модули не грузятся с `file://`).

## Что внутри

### Генерация мира (`src/world/generate.js`)
* Сетка дорог → кварталы, у каждого квартала свой район: **даунтаун**, **жилой**,
  **промышленный**, **парк**, **стоянка**, **пустошь** (распределение зависит от
  расстояния до центра карты).
* Здания собираются из настоящих комнат: рекурсивное деление прямоугольника,
  перегородки с проёмами, окна, двери, витрины-стекло, вентиляция.
* В interiors расставляется мебель по типу комнаты (кухня, спальня, склад, офис,
  магазин) и **контейнеры для лута**: холодильник, полка, шкаф, ящик, верстак.
* Улицы: тротуары, разметка, фонари (свет ночью), брошенные машины (физические
  препятствия), деревья, мусор, заборы.
* Весь мир детерминирован по сиду (можно ввести в меню).

### Зомби (`src/game/zombie.js`)
Конечный автомат: `wander → alert → chase → attack → stagger`.
* **Зрение**: ночью видят хуже (радиус зависит от освещённости точки), в упор
  чувствуют игрока даже за спиной, проверяется линия видимости по тайлам.
* **Слух**: выстрелы, шаги, вскрытие контейнеров и крики создают события шума —
  зомби идут на источник.
* **Типы**: walker (медленный), runner (быстрый), crawler (мелкий, шустрый),
  brute (толстый, много HP и урона).
* Сталкиваются друг с другом (толпа), обходят стены (локальное объездное
  движение), **ломают двери**, оглушаются от отброса.

### Физика (`src/game/physics.js`)
* AABB/круг против тайлов, раздельно по осям + скольжение вдоль стен.
* Прямоугольные препятствия (машины, деревья).
* Раздвигание толпы зомби (separation forces).
* Снаряды летят с отдачей, разлетаются от препятствий, пробивают стекло,
  оставляют кровь и трупы.

### Выживание
Здоровье, стамина, голод, жажда, кровотечение, обезболивающие, уровни и опыт,
мораль. Ночь длиннее и опаснее: население растёт, зомби активнее и видят дальше.
Можно **спать в кровати** до утра (но могут разбудить).

### Интерфейс
HUD (полосы, часы, статус-бейджи, хотбар, лог событий), инвентарь на 40 слотов
с экипировкой, панель крафта, миникарта, полноценная карта города, меню паузы
(громкость, зум), экран смерти.

### Погода
Ясно / облачно / дождь: дождь гасит свет, рисует капли, добавляет шум дождя
и влияет на видимость.

## Структура

```
index.html            разметка HUD и экранов
styles.css            стиль интерфейса
src/
  main.js             игровой цикл, состояния, системы (спавн, шум, погода, сон)
  core/
    rng.js            seeded PRNG + value noise + fbm
    input.js          клавиатура/мышь с edge detection
    audio.js          процедурный WebAudio-звук (выстрелы, рык, дождь...)
    particles.js      кровь, искры, дым, гибы, гильзы
  world/
    tiles.js          определения тайлов + генерация пиксель-атласа
    generate.js       генерация города
    render.js         отрисовка мира
    light.js          освещение (ambient, лампы, конус фонаря, light grid для ИИ)
  game/
    player.js         игрок: движение, стамина, потребности, инвентарь
    zombie.js         зомби и ИИ
    combat.js         ближний бой, огнестрел, пули, огонь
    physics.js        коллизии, LOS, разделение тел
    items.js          каталог предметов
    loot.js           таблицы лута
    crafting.js       рецепты
    sprites.js        отрисовка персонажей, иконок, машин, деревьев
  ui/
    hud.js            HUD
    inventory.js      инвентарь + крафт
    minimap.js        миникарта и карта
```

## Технические заметки

* Никаких зависимостей и сборки: чистый ES2020 + Canvas 2D.
* Атлас тайлов генерируется один раз при старте (36 типов × 4 варианта).
* Мир 3200×2400 px рисуется только по видимой области; 60 FPS при ~120 зомби.
* Свет считается в сетке 4×4 тайла и пересчитывается 5 раз в секунду — этого
  хватает и для картинки, и для «зрения» зомби.
* Звук синтезируется на лету (WebAudio): шум + фильтры + осцилляторы.
