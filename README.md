## 🎯 О проекте

**DevInspector Ultra** — это ультра-компактное (всего **50 КБ!**), молниеносное приложение для комплексной диагностики и аудита Android-смартфонов и планшетов. В отличие от тяжёлых утилит размером 30–80 МБ, DevInspector написан на чистом нативном Android API без раздутых зависимостей и фреймворков, запускается за доли секунды и считывает максимум информации об оборудовании, операционной системе и ядре Linux.

Особая гордость приложения — раздел **«Скрытые функции»**, который проникает на уровень ядра Linux, загрузчика и приватных IPC-сервисов, отображая параметры, о существовании которых часто не подозревают даже рядовые разработчики прошивок.

## 🚀 Основные возможности

### 1. 📊 Общий обзор (Dashboard)
* Модель, производитель, бренд, плата (Board), системный продукт.
* Модель процессора/SoC, архитектура и количество активных ядер.
* Текущая версия Android, API Level, дата патча безопасности Google.
* Графический мониторинг занятой и свободной оперативной памяти (RAM).
* Заполненность внутреннего накопителя (Flash ROM).
* Уровень заряда и текущий статус аккумулятора.
* Разрешение экрана, плотность DPI и частота обновления (Гц).
* Время непрерывной работы системы (Uptime).
* Проверка наличия Root-прав (SU, Magisk, KernelSU) и режима SELinux.

### 2. ⚡ Процессор и SoC (CPU)
* Модель чипсета (Snapdragon, Dimensity, Helio, Exynos, Tensor, Kirin и др.).
* Архитектура (ARMv8, ARMv9, x86_64, 32/64-bit статус).
* Список всех поддерживаемых ABI (arm64-v8a, armeabi-v7a).
* **Мониторинг частоты каждого ядра в реальном времени** с графическими индикаторами загрузки.
* Минимальные и максимальные частоты масштабирования (`scaling_min_freq`, `scaling_max_freq`).
* Текущий регулятор частоты (CPU Governor: schedutil, performance, interactive).
* Поддерживаемые инструкции процессора из `/proc/cpuinfo` (FP, ASIMD/NEON, AES, SHA1, SHA2, CRC32, atomics).
* CPU Implementer, Architecture, Variant, Part, Revision, BogoMIPS.

### 3. 💾 Память и Накопители
* Общий объём, занято, свободно RAM, порог срабатывания Low-Memory Killer (LMK).
* Глубокая статистика `/proc/meminfo`:
  * `MemAvailable`, `Buffers`, `Cached`, `Active`, `Inactive`, `Dirty`, `Writeback`.
  * **ZRAM / Swap компрессия**: общий объём свопа, процент использования, экономия памяти.
* Накопители:
  * Внутренний раздел пользователя (`/data`): общий объём, занято, свободно.
  * Системный раздел прошивки (`/system`).
  * Внешняя карта памяти SD-card (при наличии).
  * Таблица смонтированных файловых систем из `/proc/mounts`.

### 4. 🔋 Аккумулятор и Питание
* Процент заряда батареи с графической шкалой.
* Статус (Заряжается, Разряжается, Заряжен, Не заряжается).
* Источник питания (Сетевое ЗУ 220V, USB-порт, Беспроводная Qi-зарядка).
* Состояние здоровья ячеек (Good, Overheat, Dead, Over Voltage, Cold).
* Температура аккумулятора в реальном времени (°C / °F).
* Текущее напряжение ячеек (mV и Вольты).
* Технология аккумулятора (Li-ion, Li-poly).
* **Номинальная ёмкость аккумулятора (mAh)** через рефлексию скрытого класса `PowerProfile`.
* Мгновенный ток заряда/разряда (mA) и счётчик накопленной энергии.

### 5. 📱 Экран и Графика (Display & GPU)
* Физическое разрешение матрицы (Real Metrics, например 1080x2400) и рабочая область.
* Соотношение сторон экрана (например 20:9, 19.5:9).
* Расчётная физическая диагональ дисплея в дюймах на базе `xdpi` и `ydpi`.
* Плотность пикселей (DPI) и категория плотности (xxxhdpi, xxhdpi, xhdpi).
* Частота обновления экрана (60, 90, 120, 144 Гц) и поддерживаемые режимы `Display.Mode`.
* Поддержка контента с расширенным динамическим диапазоном **HDR** (Dolby Vision, HDR10, HDR10+, HLG).
* Поддержка широкого цветового охвата **Wide Color Gamut** (DCI-P3 / BT.2020).
* Версия OpenGL ES и информация о графическом ускорителе (EGL / Vulkan).

### 6. 📡 Сеть и Беспроводная связь
* Активное подключение (Wi-Fi, Mobile Data, VPN, Ethernet).
* Параметры Wi-Fi: SSID, BSSID точки, уровень сигнала RSSI в dBm (с процентом качества), частота канала (2.4 ГГц, 5 ГГц, 6 ГГц Wi-Fi 6E/7), скорость линка, MAC-адрес.
* Полный список локальных сетевых адресов IPv4 и IPv6 интерфейсов.
* Сотовая связь: имя оператора SIM, код сети (MCC+MNC), домашняя сеть, статус роуминга, готовность SIM-карты, тип радиотелефонного модуля (GSM, LTE, 5G).
* Bluetooth: статус, поддержка BLE, Bluetooth 5.0 LE 2M PHY, LE Coded PHY, расширенная реклама.
* Поддержка NFC, Wi-Fi Direct (P2P), Ultra-Wideband (UWB), Инфракрасного порта (IR Blaster) и USB OTG Host.

### 7. 🧭 Аппаратные Датчики (Sensors Explorer)
* Обнаружение и перечисление всех аппаратных датчиков устройства.
* Для каждого сенсора: тип, производитель, версия, энергопотребление в мА, диапазон измерения, разрешающая способность, задержка опроса (Min Delay), флаги Wake-Up.
* **Интерактивный Live-монитор**: выберите любой датчик из списка (акселерометр, гироскоп, магнитометр, освещённость, барометр) и наблюдайте за динамическим изменением координат X, Y, Z в реальном времени!

### 8. 📷 Камеры
* Опрос модулей камер через Camera2 API (основная, фронтальная, ультраширокоугольная, телефото, макро).
* Реальное разрешение матриц в мегапикселях и пикселях (Ш x В).
* Фокусное расстояние (мм) и эквивалент.
* Светосила/диафрагма (Aperture, например f/1.8).
* Физический размер фотоматрицы.
* Наличие вспышки, оптической и электронной стабилизации (OIS/EIS).
* Аппаратный уровень поддержки Camera2 (LEVEL_3 / FULL / LIMITED / LEGACY).

### 9. 🌡️ Термальные зоны (Thermal Zones)
* Считывание температуры со всех физических термодатчиков системы `/sys/class/thermal/thermal_zone*` (CPU, GPU, батарея, радиомодем, температура корпуса skin).
* Отображение в выбранных единицах (°C или °F).
* **Статус системного троттлинга**: отслеживание перегрева через Android PowerManager Thermal API (None, Light, Moderate, Severe, Critical, Shutdown).

### 10. 🎬 Мультимедиа, Кодеки и DRM
* **Widevine DRM**: уровень безопасности (L1 с поддержкой Full HD / 4K в стримингах vs L3), System ID, вендор, версия CDM.
* Разделение кодеков на аппаратные (Hardware Accelerated) и программные (Software).
* Перечень видеокодеков (AV1, HEVC/H.265, AVC/H.264, VP9) и аудиокодеков (AAC, Opus, FLAC, AC-3).

### 11. 🕵️ Скрытые и Недокументированные функции
> *«Смотреть функции, которые неизвестны даже разработчикам телефона»*
* **Kernel Boot Command Line (`/proc/cmdline`)**: чтение исходной строки параметров, переданной ядру Linux загрузчиком при старте смартфона. Раскрывает инженерные флаги, параметры отладки, серийный номер бутлодера, слот A/B обновлений.
* **Скрытые системные IPC-службы**: обращение к `android.os.ServiceManager.listServices()` через рефлексию. Находит сотни закрытых фоновых служб, включая приватные сервисы вендоров (Samsung Sec/Knox, Xiaomi MIUI, Qualcomm QTI/QSP, MediaTek, Oppo Oplus).
* **Криптографическая подсистема ядра (`/proc/crypto`)**: анализ всех встроенных в ядро алгоритмов и драйверов аппаратного шифрования (ARMv8 Crypto Extensions: AES-CE, SHA2-CE, ChaCha20-NEON, GHASH).
* **Скрытые флаги безопасности и загрузчика**:
  * `ro.boot.verifiedbootstate` (green / yellow / orange / red)
  * `ro.boot.flash.locked` (статус блокировки загрузчика)
  * `ro.boot.vbmeta.device_state`
  * `ro.boot.slot_suffix` (активный слот партиций `_a` или `_b`)
  * `ro.boot.warranty_bit` / `ro.boot.knox.warrantydone` (счётчик Knox)
  * `ro.debuggable`, `ro.secure`, `ro.adb.secure`
  * `ro.crypto.state` и `ro.crypto.type` (FBE/FDE шифрование)
  * `ro.treble.enabled`, `ro.apex.updatable`, `ro.oem_unlock_supported`
* **Каталог инженерных сервисных кодов (Dialer Codes)** для быстрого набора в звонилке (`*#*#4636#*#*`, CIT меню, EngineerMode).

### 12. 📋 Полный дамп системных свойств (`getprop`)
* Инспекция более **500 системных параметров** устройства.
* Быстрый живой поиск по названию или значению параметра на лету.
* Фильтрация по категориям: *Все, Android, Загрузка, Вендор, Безопасность, Сеть*.
* Копирование любого свойства в буфер обмена в одно касание.

### 13. ⚙️ Настройки и Экспорт
* **3 темы оформления**:
  * `Cyber Dark` — стильный киберпанк с неоново-синими акцентами.
  * `AMOLED Black` — абсолютно чёрный фон (`#000000`) для экономии батареи на OLED-экранах.
  * `Slate Night` — мягкие тёмно-графитовые тона.
* **Единицы измерения**: переключение градусов (°C / °F) и частот процессора (МГц / ГГц).
* **Интервал автообновления**: 1 сек, 2 сек, 5 сек или ручное обновление по кнопке.
* **Тумблер глубокого анализа (Deep Probing Mode)**.
* **Экспорт отчёта**: формирование красивого подробного текстового отчёта со всеми характеристиками телефона и возможность скопировать его в буфер обмена или поделиться через Telegram, WhatsApp, заметки или email.

## 🛠️ Сборка из исходников

Для сборки APK на любом компьютере с Linux/macOS требуется только Python 3 и Java:

```bash
# Клонирование репозитория
git clone https://github.com/Korimuspast1/hjgyj.git
cd hjgyj

# Запуск автоматической сборки
./build.sh
```

Готовый файл будет создан в папке `dist/DevInspector-Ultra-v1.0.apk`.
